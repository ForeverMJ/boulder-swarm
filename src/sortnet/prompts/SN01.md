# SN01 - land any verified sorting network for n=16

You are the worker for task SN01. Produce a correct sorting network for 16 inputs. This
task is about landing a checker-verified artifact, not beating a size record.

## Deliverables - exactly two files

1. Create `src/sortnet/attempts/SN01_net16.ts`. It must export
   `export const network: Network` with `network.n === 16`.
2. Create `src/sortnet/attempts/SN01_net16.test.ts`. It must import that network and
   assert `checker.verify(network).correct` is `true`.

You may import from `src/sortnet/checker.ts`, `src/sortnet/types.ts`, and
`src/sortnet/tools/batcher.ts`. You may read any repository file to understand the
interfaces and style.

## Hard scope restriction (load-bearing)

- You MUST create ONLY `src/sortnet/attempts/SN01_net16.ts` and
  `src/sortnet/attempts/SN01_net16.test.ts`.
- You MUST NOT modify, delete, rename, or generate any other file.
- In particular, do not modify the checker, scoreboard, goal gate, bounds, Batcher tool,
  seed networks, campaign docs, or another worker's attempt.

## Acceptance

Run `bun test src/sortnet/attempts/SN01_net16.test.ts`. Success requires the exact
checker to accept all 2^16 binary inputs.
