# SN06 - beat Batcher for n=15

You are the worker for task SN06. Produce a correct sorting network for 15 inputs that is
strictly smaller than the generated Batcher baseline. `batcherNetwork(15)` has 59
comparators, so your network must have at most 58 comparators.

## Useful starting points

- `src/sortnet/attempts/SN02_net11.ts` (37 comparators, n=11) and
  `src/sortnet/attempts/SN03_net12.ts` (41 comparators, n=12) already beat Batcher;
  you may READ them for construction ideas (e.g. extending a smaller network, merging,
  wiring an extra channel into an existing network). You MUST NOT modify them.
- The published best-known size for n=15 is listed in `src/sortnet/bounds.ts` —
  treat beating Batcher as the gate, and get as close to best-known as you can.

## Deliverables - exactly two files

1. Create `src/sortnet/attempts/SN06_net15.ts`. It must export
   `export const network: Network` with `network.n === 15` and fewer than 59 comparators.
2. Create `src/sortnet/attempts/SN06_net15.test.ts`. It must import that network, assert
   `checker.verify(network).correct` is `true`, and assert its comparator count is less
   than `batcherNetwork(15).comparators.length`.

You may import from `src/sortnet/checker.ts`, `src/sortnet/types.ts`, and
`src/sortnet/tools/batcher.ts`. You may read any repository file to understand the
interfaces and style.

## Hard scope restriction (load-bearing)

- You MUST create ONLY `src/sortnet/attempts/SN06_net15.ts` and
  `src/sortnet/attempts/SN06_net15.test.ts`.
- You MUST NOT modify, delete, rename, or generate any other file.
- In particular, do not modify the checker, scoreboard, goal gate, bounds, Batcher tool,
  seed networks, campaign docs, or another worker's attempt.

## Acceptance

Run the colocated test, then run `bun src/sortnet/scoreboard.ts`. Success is judged by
the machine marker `N15BEATBATCHER=SN06_net15.ts`.
