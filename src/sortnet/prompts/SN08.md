# SN08 - beat the best-known size for n=13 (open challenge)

You are the worker for task SN08. The best-known sorting network for 13 inputs has 45
comparators (Dobbelaere's table; see src/sortnet/bounds.ts). This is NOT a proven optimum
— the published lower bound is smaller, so a correct network with at most 44
comparators would be a genuine new record. Your task: try to find one.

This is an open challenge, not a routine task. If you cannot beat 45, the honest outcome
is a failed task — do NOT submit a network with 45 or more comparators as if it won;
the machine marker judges, and a non-improving network changes nothing.

## Strategy hints

- Start from `src/sortnet/attempts/SN0*_net13.ts` if one exists (READ ONLY) or the
  published 45-comparator construction; try local improvements: remove a comparator and
  rewire, swap comparator order, optimize the last layers (most slack lives there), or
  grow/shrink channels from the n=12 or n=14 constructions.
- You may compute the network at import time (a bounded search inside your attempt file),
  but the import MUST finish in under 60 seconds — the scoreboard imports your file and
  a hung or slow import counts as a failure.
- Verify every candidate with `checker.verify(network).correct` before exporting it.
  An incorrect "record" is worthless; the 0/1-principle check will find a counterexample.

## Deliverables - exactly two files

1. Create `src/sortnet/attempts/SN08_net13.ts` exporting `export const network: Network`
   with `network.n === 13` and at most 44 comparators.
2. Create `src/sortnet/attempts/SN08_net13.test.ts` asserting
   `checker.verify(network).correct === true` and the comparator count is at most 44.

You may import from `src/sortnet/checker.ts`, `src/sortnet/types.ts`, and
`src/sortnet/tools/batcher.ts`. You may read any repository file.

## Hard scope restriction (load-bearing)

- You MUST create ONLY `src/sortnet/attempts/SN08_net13.ts` and
  `src/sortnet/attempts/SN08_net13.test.ts`.
- You MUST NOT modify, delete, rename, or generate any other file, including the checker,
  scoreboard, goal gate, bounds, Batcher tool, seeds, docs, or another worker's attempt.

## Acceptance

Run the colocated test, then `bun src/sortnet/scoreboard.ts`. Success is judged by the
machine marker `N13BEATBESTKNOWN=SN08_net13.ts`.
