# SN03 - beat Batcher for n=12

You are the worker for task SN03. Produce a correct sorting network for 12 inputs that is
strictly smaller than the generated Batcher baseline. `batcherNetwork(12)` has 42
comparators, so your network must have at most 41 comparators.

## Deliverables - exactly two files

1. Create `src/sortnet/attempts/SN03_net12.ts`. It must export
   `export const network: Network` with `network.n === 12` and fewer than 42 comparators.
2. Create `src/sortnet/attempts/SN03_net12.test.ts`. It must import that network, assert
   `checker.verify(network).correct` is `true`, and assert its comparator count is less
   than `batcherNetwork(12).comparators.length`.

You may import from `src/sortnet/checker.ts`, `src/sortnet/types.ts`, and
`src/sortnet/tools/batcher.ts`. You may read any repository file to understand the
interfaces and style.

## Hard scope restriction (load-bearing)

- You MUST create ONLY `src/sortnet/attempts/SN03_net12.ts` and
  `src/sortnet/attempts/SN03_net12.test.ts`.
- You MUST NOT modify, delete, rename, or generate any other file.
- In particular, do not modify the checker, scoreboard, goal gate, bounds, Batcher tool,
  seed networks, campaign docs, or another worker's attempt.

## Acceptance

Run the colocated test, then run `bun src/sortnet/scoreboard.ts`. Success is judged by
the machine marker `N12BEATBATCHER=SN03_net12.ts`.
