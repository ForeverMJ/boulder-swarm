The three things that must not be fudged:

- ORDERING. On timeout, `onSalvage` MUST be called while the tree is still
  alive, and only then may the tree be killed. The judge asserts that inside the
  salvage callback `countTree(pid) > 0`. If you kill first and salvage after,
  the salvaging agent has already been killed and the work is still lost. This
  is the bug that cost round 41 its result.
- NO STRAYS. After `runTree` returns, `straysAfter` must be 0 and the judge also
  checks independently that BOTH the parent and the grandchild pid are dead.
  `killTree` must WAIT for processes to actually exit, not merely signal them.
- HONEST TIMING. `timedOut` must be true only when the deadline actually fired,
  and a clean nonzero exit must not be reported as a timeout. The judge runs a
  command that exits 3 and expects `timedOut === false`.

Make `runTree` capture stdout, since the judge asserts on it.
