    4/n = 1/x + 1/y + 1/z      (positive integers, x <= y <= z)

You must use exact rational arithmetic (BigInt). Floats must not appear in the equality
decision. A useful bound from 1/x + 1/y + 1/z = 4/n with x <= y <= z:

    n/4 < x <= 3n/4,   so x runs over at most n/2 candidates per n

For each candidate x, the remainder r = 4/n - 1/x = (4x - n) / (nx) needs two unit
fractions 1/y + 1/z = r; with y <= z, y is bounded by the divisors of r when written
as a reduced fraction a/b — y ranges over divisors b' of b such that ... (work it out
exactly; the divisor structure of a/b decides finitely many candidates `y`).
