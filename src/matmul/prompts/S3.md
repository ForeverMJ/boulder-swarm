  seconds apart. If `waitForExit` rejects, do NOT commit — the judge asserts
  `commitProduced` was never called, because committing against a process that is
  still writing is what destroys work.
- HONEST EMPTY COMMIT. `emptyCommit` must be true when `commitProduced` returns
  an empty list, even though nothing threw. A commit that reports success while
  producing no files is exactly how round 41 recorded `committed: true` for
  work that never reached the branch. Report it as producing nothing.

as solved; the judge checks `total` is passed through untouched, and inventing a
solved verdict from an unparsed 0/0 is the defect being fixed.
