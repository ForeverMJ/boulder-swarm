You are worker for task T12b. Same open target as T12 (correct exact 3x3 scheme,
rank <= 22), but your route is COMPUTATION: write and run search programs in
TypeScript, let the machine explore. Do not hand-derive; code the search.

Setup you already have: src/matmul/types.ts (Scheme), src/matmul/checker.ts
(exact verify, use it as your objective), src/matmul/schemes.ts (naive(3) baseline,
strassen2x2 format demo). Scoreboard: `bun src/matmul/scoreboard.ts`.

Search program requirements:
1. Objective: mismatches (0 = solved) primary, rank secondary. Start from naive(27)

2. Mandatory techniques (implement at least two):

     re-verify exactly after each restart.
   - Large-neighborhood / simulated-annealing search over {-2,-1,0,1,2} with a
     time budget you monitor yourself (keep single runs under 4 minutes).
   - Drop-k repair: remove 1-2 triples from a rank-23 scheme, then repair the
     residual with fresh triples (bounded enumeration over sparse supports).
3. Every run must print: iterations, best mismatches, best rank. Save scripts under
   src/matmul/attempts/ as T12b_<name>_search.ts (they may be long-running; keep
   each under the time budget and checkpoint best-so-far to disk).
4. Save your best scheme as src/matmul/attempts/T12b_<name>.ts exporting scheme,
   with a header comment documenting: method, iterations, best mismatches, rank,
   and why you stopped. Partial (correct, rank 23, new family) still counts as data.

Never modify checker.ts, types.ts, schemes.ts, tests, or scoreboard.ts.
Print exactly one final line: FINAL: {"task_id":"T12b","verdict":"PASS or FAIL","passed":n,"total":m}
where passed = 1 if your scheme is correct and rank <= 22 else 0, total = 1.
